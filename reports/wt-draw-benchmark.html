4. 本轮落地明细

4.1 出图规范集中配置（drawingStandard.cs）

  • 预设：project（项目现状，字高 2.5 / A0 / 1:50 / 45°→135°，零行为变化）、HG20519（A1 / 字高 5·3.5·3.5·7 / 线宽 0.7·0.35·0.2 / 长仿宋）、SH3052（线宽 0.7·0.5·0.25）。
  • 参数覆盖（每次 op 生效，互不串值）：standard、frameSize、stdScaleDen、textHeight、dimTextHeight、tableTextHeight、titleHeight、lineHeavy/lineMid/lineThin、leaderAngle/leaderAltAngle/leaderPrefer、font、以及 15 个 layer* 图层名/色/线型覆盖键。
  • 合规校验 Validate()：字高下限、A0/A1 字高、线宽三档区间与大小关系、常用比例、45/135 引线、图幅；全部只写 [STD-WARN] 日志，不中断出图。
  • 接入点：headlessDrawing.cs 的 CreateDrawing / ReplaceSymbols 开头写 [STD] 摘要与告警；9j 引线角度改走 LeaderAngles()（默认仍是 45/135）；layerManager.cs 层名/色/线型/CHEI 走标准（默认与旧值完全一致）。
  • 边界说明：线宽目前只记录与校验，不推入 PDMS STYL/pen 表——直接改会改变现有出图效果，留到 P2 实测后再接。

用法示例：出图参数里加 {"standard":"HG20519"} 或 {"standard":"SH3052","textHeight":"5","leaderPrefer":"left"}；op 日志会打印 [STD] preset=... 作为无人值守证据。

4.2 批量出图驱动（bridge/batch_draw.py + batch_jobs.example.json）

  • 复用现有 wizard.pipeline（replace_symbols → SAVEWORK → export_pdf → 黑白 → 预览），不改生产链代码。
  • 关键设计：每张图临时把 wizard.OUTDIR 指向自己的 work/<job>/，避开单图流水线固定 preview.pdf 互相覆盖/取错 PDF 的坑；完成后 PDF 归档到 pdf/<job>.pdf、日志到 logs/<job>.log。
  • 状态 state.json 每图即时落盘；--resume 跳过成功图、--retry N 重跑失败图、--only 指定子集、--dry-run + --fail 离线演练。
  • 批次产出：report.md（人读）/ report.json（机器读）/ pdf / logs / work。

真实运行：python bridge/batch_draw.py bridge/batch_jobs.example.json --out D:\pdmsAgent\bridge\batch_out（示例清单的 view/sheet/elements 是占位符，需替换；PDMS + bridge 必须在线）。
